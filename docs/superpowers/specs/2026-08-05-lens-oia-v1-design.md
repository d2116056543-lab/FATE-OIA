# LENS-OIA V1 Design

LENS keeps the ACPR CalAlign-compatible visual action path as its source reference, uses label-specific null-aware evidence to form an identifiable present/counter/unknown state, and uses only clean observable log-odds in the action fusion. Ordered emission is a benchmark-reason observation model and must not change action. The action rereader uses all 3600 detail patches with factor maps as finite biases, and exposes exact named plus unnamed residual contributions.

Structured BDD100K information is fail-closed, trainer-only grounding supervision. The model accepts RGB and progress only. Calibration is fitted after each epoch on train-calib and cannot mutate model weights; test selection is internal only and marked non-publication eligible.
