## Pilot 取证与语义修复（2026-08-06）

- `c9b336c` 四轮真实 pilot 完成，Action 路径为明确正向：epoch 3 `Act_mF1 0.65624 -> 0.67944`、`Act_mAP 0.74514 -> 0.75531`；selected-control gap `+0.12847`，贡献/effect Spearman `0.63489`。这排除了“整个 AIE 外壳无效”。
- Reason 的 F1 上升但排名退化：epoch 3 `Exp_mF1 0.22179 -> 0.24987`，`Exp_mAP 0.26930 -> 0.26327`。checkpoint 取证显示 reason residual 均值 `+2.368`，但 action-prior off 仅改变 logits RMS 约 `0.0011`，predicate-prior off 差异为严格 `0`。
- 同 checkpoint 的 16 张固定 test 前向显示：Reason visual score std `3.119`，action prior bias 几乎常数，predicate prior bias完全常数；视觉点积饱和使 bounded prior 不能参与读取。
- Naming 并非随机：grounded quality 优于 random 的比例约 `0.97`；但 256 atoms 中固定门槛命名数为 `0`。分解为 SoftIoU 均值 `0.0642`、compatibility 均值 `0.4985`、top presence 全为 `1.0`，确认是绝对尺度/监督缺口而非单纯阈值运气。
- 代码追踪发现三项遗漏：Reason Q/K 未控制尺度；命名 compatibility 额外除以计划中不存在的 `sqrt(64)`；builder 生成的 `predicate_counter_mask` 未进入 predicate loss，导致近似正例-only监督和 presence 饱和。
- RED tests 已复现以上缺陷；修复后新增/全量 AIE 测试分别 `7 passed`、`71 passed`：Q/K 使用无参数 LayerNorm；predicate counter 进入 masked ASL 且 unknown 梯度为零；primary/final Reason 辅助损失共用 evidence-censored PU 权重；compatibility 恢复计划原始未缩放内积；artifact 增加 naming 三因子和 reason score/prior bias。
- 当前仍不声明 `FULL_TRAIN_READY`：必须由新 HEAD 的 clean audit、真实短诊断和重新绑定的正式 pilot 证明 predicate saturation、Reason prior sensitivity 与 Exp mAP 已得到实际改善。
