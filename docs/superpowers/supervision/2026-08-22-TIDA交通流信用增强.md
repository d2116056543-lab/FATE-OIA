# TIDA 交通流信用增强监督记录

## 目标

在冻结 VETRA 强图像分支的前提下，让有序交通流对 action 和 explanation 产生可测量的正贡献，而不是只产生非零 gate 或非零 delta。

## 已确认问题

- 当前 terminal predictor 的 history/no-history 两条路径都接收当前目标帧静态上下文，形成静态捷径。
- shuffle/reverse/repeat 只约束终点重建，没有直接约束 action/reason 的 GT margin。
- action base protection、较小 residual 和 trust cap 共同使 action temporal delta 收敛到接近零成为安全解。
- 已有 differential 包含速度、加速度、区域质量变化和 persistence，但没有被 target-specific credit 明确监督。
- 现有结果只能证明 context-aware，尚不能证明强 flow-aware。

## 选定方案

采用显式 signed transition bank、action/reason 私有 flow reader、same-image counterfactual GT-margin credit，并保留严格的 image fallback 和 reason-to-action 梯度防火墙。拒绝通过更强 backbone、光流预处理或削弱图像基线制造增益。

## 审查边界

- 分支非零不等于有效。
- 反事实有差异不等于最终指标净增益。
- 只有 ordered history 同时改善 GT margin 与最终指标，才可以声明交通流发挥正向作用。
- 如果仅 history-off 有影响而 shuffle/reverse 无影响，只能声明上下文有效，不能声明交通流方向有效。
