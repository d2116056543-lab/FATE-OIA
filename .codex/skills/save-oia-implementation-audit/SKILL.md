# SAVE-OIA implementation audit

Use this skill before SAVE pilot or full training. The audit is fail-closed for
source/worktree, forbidden paths, full-CalAlign base, frozen one-call DINO,
global-to-utility-to-detail ordering, contribution conservation, clean/private
firewalls, loss uniqueness, exact optimizer ownership, train-audit-only PU,
artifact/resume bindings, same-field test interventions, and foreground-only
supervision.

Run `python -m fate_oia.engine.audit_save_oia --config
configs/fate_oia_train_360x640_save_oia_v1.yaml --output-dir <dir>
--write-review-pass` from the dedicated SAVE worktree. A REVIEW pass is only
implementation closure. Read pilot raw evidence and rank raw/deploy Action,
Exp and joint metrics before choosing a full-train candidate; never replace a
stronger stable metric result solely because a heuristic pilot gate was missed.
